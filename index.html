The under-the-hood work that moves rankings

Most "SEO" stops at keywords. Mine starts at the server log and ends at a passing Core Web Vitals report.

Technical SEO audit → fix → verify

Diagnosed with Ahrefs, Screaming Frog & Search Console. Fixed at the code level.

  • Server log analysis — crawl budget, speed index & server response time improvements visible in Search Console
  • Advanced schema markup (JSON-LD) for rich results
  • Google Business Profile optimization & local SEO
  • Full Ahrefs + Screaming Frog site audits
  • Search Console issue resolution (indexing, coverage, enhancements)
  • Core Web Vitals — LCP, CLS & INP fixes
  • XML sitemaps, robots.txt & crawl directives
  • Canonicalization, redirects & duplicate-content cleanup
  • Internal linking architecture & orphan-page fixes
  • Hreflang & international SEO setup

Speed Optimization 95+ PageSpeed

Manual, measured optimization — not just installing a caching plugin.

  • Cloudflare setup — CDN, edge caching & security rules

  • Hand-optimized images (WebP/AVIF, compression, lazy loading)

  • Font optimization — preload, subsetting & display swap
  • Database cleanup & query optimization
